# WARNO 한국어 번역 원칙

이 문서는 `English` 원문을 `Korean`으로 수동 번역할 때 적용하는 기준이다. 번역 중 새 판단이 생기면 계속 갱신한다.

## 작업 방식
- 영어 → 한국어 수동 번역만 사용한다.
- 전역 문자열 치환, 찾아바꾸기식 번역, 외부 번역 라이브러리, 로컬 번역 모델을 사용하지 않는다.
- 각 항목은 TOKEN, 파일 종류, 주변 문자열, WARNO의 냉전 군사 문맥을 보고 개별 판단한다.
- 원본 기준 1,000라인 번역할 때마다 체크포인트를 만든다. 파일이 1,000라인 미만이면 파일 끝에서 체크포인트를 만든다.
- 체크포인트마다 TOKEN, 자리표시자, 태그, 줄바꿈을 검수한다.

## 보존
- TOKEN과 행 순서
- `%1`, `%2`, `{0}` 등의 자리표시자
- `#bold{}`, `#cyan{}`, `#green{}`, `#U1{}` 등의 게임 서식 태그
- 무기/차량/항공기 제식명, 식별에 필요한 부대 고유명
- NATO/소련권 표준 약어와 탄종/구경 표기(SACLOS, HEAT, APFSDS, ERA, ECM, SEAD 등)는 문맥상 번역이 더 명확하지 않으면 원문 표기를 유지

## 문체
- 버튼/메뉴: 짧고 즉시 이해되는 한국어
- 툴팁/설명: 게임 규칙과 조건이 정확히 전달되는 자연스러운 한국어
- 같은 개념은 용어집을 기준으로 일관되게 쓰되 문장 전체는 문맥에 맞춰 번역
- 임의의 의미 추가/삭제 금지

## 기본 군사 용어
- attacker: 공격측
- defender: 방어측
- battlegroup: 전투단
- command point(s): 지휘 점수
- action point(s): 행동 점수
- command unit: 지휘 유닛
- recon: 정찰
- supply: 보급
- engineer: 공병
- infantry: 보병
- airborne: 공수
- air defense: 방공
- anti-aircraft: 대공
- anti-tank: 대전차
- artillery: 포병
- field artillery: 야전포병
- battalion: 대대
- company: 중대
- platoon: 소대
- regiment: 연대
- brigade: 여단
- division: 사단
- corps: 군단

## 검수
- UI 파일에는 의도적으로 보존한 약어/고유명 외 영어 일반 문구가 남지 않게 한다.
- 동일 개념의 번역이 흔들리면 용어집을 먼저 수정하고 관련 항목을 다시 검토한다.
- 수치, 승패 조건, 사거리/방어/명중 관련 인과관계는 원문을 정확히 보존한다.
